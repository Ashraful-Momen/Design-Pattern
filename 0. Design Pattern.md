## 🔥 আমি এটাকে 5টা Core Pattern-এ নামিয়ে আনব

### 🥇 Core 1 — Dependency Injection

**শিখবে:**

> Object তার dependency নিজে create না করে বাইরে থেকে নেয়।

```text
Class
 ↑
Dependency
```

এটা ভালোভাবে বুঝলে:

* DI
* IoC
* Container
* Service Container
* Dependency management

অনেক সহজ হয়ে যাবে।

**এটা অবশ্যই Deeply শিখবে।**

---

### 🥈 Core 2 — Factory

**মূল প্রশ্ন:**

> কোন object তৈরি করব?

```text
Factory
   ↓
Object
```

Factory বুঝলে:

* Factory Method
* Abstract Factory
* বিভিন্ন Object Creation Pattern

বোঝা সহজ হবে।

**Deeply শিখবে।**

---

### 🥉 Core 3 — Strategy

**মূল প্রশ্ন:**

> একই কাজের জন্য কোন algorithm/behavior ব্যবহার করব?

```text
Service
  ↓
Strategy
 ├── A
 ├── B
 └── C
```

এটা খুব powerful।

Strategy ভালোভাবে বুঝলে:

* State
* কিছু Command-based design
* interchangeable behavior
* polymorphism-based architecture

অনেক সহজ লাগবে।

**Deeply শিখবে।**

---

### 🏅 Core 4 — Adapter

**মূল প্রশ্ন:**

> দুইটা incompatible interface কীভাবে connect করব?

```text
Our System
    ↓
 Adapter
    ↓
External System
```

এটা বুঝলে:

* External API integration
* Payment gateway integration
* Legacy system integration
* Third-party library integration
* Wrapper-based design

অনেক সহজ হয়ে যাবে।

**Deeply শিখবে।**

---

### 🏅 Core 5 — Facade

**মূল প্রশ্ন:**

> অনেক complex subsystem-কে কীভাবে একটা simple interface-এর পিছনে রাখব?

```text
Client
  ↓
Facade
  ↓
A + B + C + D
```

এটা বুঝলে:

* Service orchestration
* Application service
* Workflow layer
* Complex subsystem abstraction

বোঝা সহজ হবে।

**Deeply শিখবে।**
